For sellers and API reviewers

How listing data is used

Read-only access to public listing information, used only to make the seller's own video.

What it reads

Only public listing information, through the marketplace's official API:

  • Listing title and description
  • Photos and price
  • Shop name
  • Public reviews

Read-only

It never edits listings and never touches orders, messages, payments or customer data. It requests no OAuth seller permissions.

How it's used

Only to write the script and place the seller's own listing photos in the seller's own video. Nothing is resold or shared with third parties.

Storage

Listing data is cached briefly to build the video. It is not stored as a database of marketplace content.
